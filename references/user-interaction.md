# Interaction

A bare subject name is enough. Use soft clay, natural subject colors, transparent PNG and the shared style defaults without a questionnaire.

- Direct generic request: generate immediately; no forced search or backup-link quota.
- Find/compare/transform request: search verified free commercial sources first; offer paid candidates when needed, with source and license links. Ask for a silhouette choice only when meaningful.
- Photo for identification: describe the generic subject; record that the photo was not passed to generation. If a specific shape must be preserved, treat it as a transformation and record rights evidence and actual input.
- “02” selects the previous candidate; palette changes retain the subject; “all” means the stated candidates, not an unlimited search.
- Deliver a file link, a short input/source disclosure and commercial-use conditions. Unknown source rights are not an explicit noncommercial license. Keep source and output status separate.
