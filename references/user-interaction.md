# Interaction

A bare subject name is enough. Use soft clay, natural subject colors, transparent PNG and the shared style defaults without a questionnaire.

- Direct generic request: generate immediately; no forced search or backup-link quota.
- Find/compare request: search verified free commercial sources first and offer paid candidates when needed, with source and license links. Ask for a silhouette choice only when meaningful. If no candidate fits, report what was checked before offering alternatives.
- Photo for identification: describe the generic subject and record how the photo was used. For an exact-shape transformation, assess the supplied image first. If the user requires commercial use and rights are unconfirmed, explain what permission is missing and leave that transformation pending.
- “02” selects the previous candidate; palette changes retain the subject; “all” means the stated candidates, not an unlimited search.
- Deliver a file link, a short input/source disclosure and commercial-use conditions. Unknown source rights are not an explicit noncommercial license. Keep source and output status separate.
